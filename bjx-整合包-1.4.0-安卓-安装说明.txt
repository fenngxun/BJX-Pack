BJX 整合包 1.4.0 — 安卓版安装说明
=====================================

文件：bjx-整合包-1.4.0-安卓.apk（173 MB）
包名：com.vrelnir.DegreesOfLewdityBJX
要求：Android 5.0 及以上（minSdk 19 / targetSdk 28）
签名：v1 + v2 + v3（SHA256withRSA），有效期至 2054 年


一、安装
--------
1. 把 apk 传到手机（数据线 / 网盘 / 微信文件传输均可）。
2. 点击安装，若提示「禁止安装未知来源应用」，按提示允许当前文件管理器安装。
3. 部分机型（小米/华为/OPPO）会弹「安全检测」或「纯净模式」拦截，
   需要手动选择「仍要安装」。
4. 若手机已装过旧版「dol星扩」APK，需先卸载——两者包名相同但签名不同，
   直接覆盖会报「应用未安装」。


二、首次启动会很慢（正常）
--------------------------
游戏本体是单个 97 MB 的 HTML，手机 WebView 解析需要时间：

  - 中端机（骁龙 7 系 / 天玑 8000 系）：约 20–60 秒
  - 低端机 / 老机型：1–3 分钟，期间可能白屏或黑屏，不要退出
  - 启动完成后进入年龄确认页，点击进入即可

已为 APK 开启 largeHeap（大内存堆），否则 97 MB 的 HTML 会直接 OOM 崩溃。


三、存储占用
------------
  - APK 本身：173 MB
  - 安装后：约 350 MB（游戏资源 33586 个文件解压到应用目录）
  - 存档：随游戏内保存，位于应用私有目录，卸载会一起删除


四、已知问题
------------
1. **mod 列表里 bjx-pack 显示版本 1.3.0** —— 内容是最新的 1.4.0
   （140 twee / 3752 passage，与桌面版完全一致），只是版本号字段没跟上。
   不影响任何功能。
2. **首次进游戏可能提示「读取存档失败」** —— 忽略即可，新装没有存档。
3. 手机 WebView 版本过旧（Android 5/6 未更新过 WebView）可能导致脚本报错。
   建议在应用商店更新「Android System WebView」。
4. 后台切换回来可能重新加载页面（内存不足时系统回收），存档不会丢。

----------------------

  - 修改项：AndroidManifest 增加 android:largeHeap="true"
  - 已验证：APK 内 HTML 与桌面发布包 sha256 完全一致
